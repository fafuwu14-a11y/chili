# 使用说明

## 一、启动

### 方式 A：双击 exe（推荐给评委和老师）

1. 打开 `dist/` 文件夹，双击 `chili.exe`
2. 黑色窗口里会出现一行地址，浏览器一般会自动打开；没打开就手动访问 `http://127.0.0.1:8000/`
3. 关掉黑窗口就是关闭服务，账号和数据都留在 `dist/data/app.db` 里

第一次启动 3–5 秒（程序在解压内置数据），之后秒开。杀毒软件可能误报，选「允许运行」即可。

### 方式 B：源码运行（推荐给要改代码的人）

```bash
cd E:\大肥鱼工作区\gaokao-platform
python -X utf8 run.py --port 8000
```

不需要装任何第三方包。想给同一 Wi-Fi 下的手机看，加 `--lan`：

```bash
python run.py --lan
```

窗口里会多打印一个局域网地址（形如 `http://192.168.1.7:8000/`），手机浏览器直接打开。

## 二、学生视角：五步走完

### 第 1 步 · 定省份（30 秒）

打开首页点「3 分钟选科」，或直接访问 `/wizard.html`。

31 个省级行政区按规则分成三组：3+1+2（23 省）、3+3（6 省市）、文理分科过渡期（西藏、新疆）。选你考试的省份——**不是户籍所在地，是参加高考的地方**。

选完会告诉你：你们省一共几种组合、从哪一年开始、物理和历史怎么二选一。

### 第 2 步 · 答 23 道题（约 6 分钟）

题都很短，问的是具体场景，不是让你给自己打分。例如：

> 学校开放一间实验室给你随便使用，你最想做什么？
> A 组装一台机器人，写程序让它自己走
> B 配试剂、看颜色变化，把一种物质提纯出来
> C 培养微生物、观察细胞，搞清楚它怎么活
> D 测地形、分析气象数据，画一张别人没画过的图

**凭第一反应选**，不要想「选哪个显得我厉害」。答案只存在你自己浏览器的当前标签页里，不上传服务器；刷新不会丢，关掉浏览器就清空。

### 第 3 步 · 看三个组合（2 分钟）

系统给三张卡，每张写清楚：

- **匹配分**：你的兴趣、能力、专业覆盖三者加权后的分数
- **可报比例**：这个组合能报 821 个专业里的多少个（例如物化地 739 个，90.0%）
- **注意**：这个组合的代价。物化生是「赋分竞争最激烈」，物化政是「避开生物高分内卷」，史政地是「理工农医基本关闭」
- **为什么是它**：点开能看到具体哪几门学科的得分在撑这个组合

不满意可以「换一批」，看第 4–6 名的组合。

### 第 4 步 · 挑专业（5 分钟）

12 张专业卡，按匹配度排。每张卡告诉你：属于哪个专业类、对不对得上你的兴趣簇、选科要求是什么。

**两个按钮**：

- **看哪些学校强** → 右侧抽屉列出全国 800 多所院校，按最近录取位次从难到易排
- **问 AI：我适合吗** → 打开专业顾问，可以问「这个专业到底学什么」「我这种性格适合吗」「和相近专业什么区别」

没配 AI 也能点，会提示去设置；主流程不受影响。

### 第 5 步 · 用一门课验证「喜欢」（10 分钟）

这一步是整个流程里最容易被跳过、但最该做的：

1. **先导课**：系统挑 3–4 门这个专业的真实大学课程（都在中国大学 MOOC、学堂在线等平台免费可看），标注了学时和难度
2. **真实的一天**：告诉你这个专业大一到大四大概怎么过，包括不好听的部分
3. **三个灵魂拷问**：愿意为它多花时间吗？学得吃力会继续吗？起薪普通还选吗？
4. **二次检验**：三道 1–5 分题，均分 ≥ 4 建议深入，2–4 建议先试课，< 2 建议换一个看看

结论会存进浏览器，下次接着看。

## 三、家长视角：三个最常问的问题

**「这个推荐准不准？」**
不准到「一定适合」，准到「值得优先了解」。分数是规则算的（可复现），AI 只负责把规则结果讲成人话。页面上所有百分比都能在 `02-规则与数据表` 里核对到原始数字。

**「为什么推荐物化地而不是物化生？」**
因为前三名的分数只差 1–2 分，系统按「兴趣契合 + 专业覆盖」的综合分排序，不是按「哪个更热门」。点「为什么是它」能看到具体是哪几门学科撑起来的。

**「能不能看到学校排名？」**
能看到学校在这个专业上的**录取位次**排名，这是公开数据。平台不引用商业排名，因为排名口径不透明、且和录取难度经常不一致。

## 四、老师视角：怎么用来做一次班会谈

1. 班会课前：让学生各自在手机上完成 23 题（一台设备 6 分钟）
2. 班会课上：投屏演示一次完整流程，重点讲「第 3 步的代价」和「第 5 步的二次检验」
3. 课后：让学生把第 3 步的三张组合卡截图交上来，作为一次选科摸底的原始材料
4. 需要批量分析时：让学生把结果页的组合与覆盖率数字填进表格，与 `表2_组合覆盖率汇总.csv` 对照

**注意**：平台不采集学生数据，老师拿不到后台的答题记录。这是设计选择——测评涉及个人倾向，不该默认上传。

## 五、接入 AI（可选）

不配 AI 也能用全部规则功能。想要 AI 追问和口语化解读，需要自己准备一个模型 Key：

1. 打开 `/ai-setup.html`（或点右上角「AI 设置」）
2. 选厂商：DeepSeek、通义千问、豆包、Kimi、智谱、文心一言、讯飞星火、腾讯混元、MiniMax、阶跃星辰、硅基流动、OpenRouter、本地 Ollama
3. 填 API Key（Ollama 不用填）
4. 点「测试连接」，通过就保存

**最省事的路径**：DeepSeek。注册后在控制台创建 API Key，充 10 块钱能用很久。

**Key 存在哪**：只存在你这台电脑的浏览器 `localStorage` 里，请求经本地服务转发，不落库、不上传。页面上只显示 `sk-****abcd`。

**13 家厂商的详细申请步骤**见 `docs/AI接入指南.md`，包含每家的控制台地址、模型名、常见报错对照表。

## 六、常见问题

**Q：不登录能看吗？**
能。首页、专业库、培优扶弱、AI 设置都不需要登录。需要登录的是三档预测、志愿表和 AI 对话（防 Key 滥用）。

**Q：有测试账号吗？**
有。登录弹窗底部写着：`demo@chili.dev` / `chili2026`，点「一键填入」即可。

**Q：手机上能用吗？**
能。响应式布局，390px 宽度下卡片单列、抽屉全宽。同一个 Wi-Fi 下用 `--lan` 启动，手机访问局域网地址即可。

**Q：数据多久更新？**
投档表每年 7–8 月录取结束后更新，选科要求每年 3–5 月更新。当前内置的是 2024–2026 三个年度、8 个省份的数据。

**Q：会不会误导学生？**
平台在所有结论页都写了同一句话：**推荐由规则引擎生成，用于缩小选择范围，不代替你、家人和老师的判断**。数据与选科要求以本省考试院公布为准。
