## 一句话说明每份材料

**01 界面截图**：17 张真机截图，覆盖选科测评、组合建议、三档联动推荐、专业推荐、院校优势抽屉、就业画像、AI 顾问（引导式提问 + 结论卡）、专业库新版、培优扶弱、AI 接入设置，另含 2 张 390px 移动端。全部对本地真实运行的服务拍摄，不是设计稿。

**02 规则与数据表**：三张可核对的 CSV——12 种组合 × 92 个专业类的可报性矩阵、组合覆盖率汇总、专业到专业类映射样例；外加就业画像 9 个字段的来源说明表。表里的数字与代码 `subjects.coverage()` 一一对应，评审可现场跑命令核对。

**03 系统与技术材料**：技术栈（零第三方依赖）、源码结构与打包说明、378 个单元测试的逐文件清单、三种视口的兼容性测试记录、离线 exe 说明。

**04 项目文档**：需求分析说明（为什么做、给谁做、验收标准）、系统设计说明（分层、关键算法、API 契约、降级策略）、数据来源与口径说明（规则 / 事实 / 判断三分法，主动披露 5 条局限）、使用说明（学生五步、家长三问、班会用法的、AI 配置）。

**05 调研材料**：**这是唯一没有实际数据的部分**。已备好访谈提纲（教师 8 问 / 学生 5 问 / 家长 6 问）、可打印问卷样张（13 题）、试点反馈汇总模板和 4 周调研计划。需要与中学对接后据实填写，我们不预先编造访谈记录。

## 交叉核对指引（给评审）

三处可以互相验证的数字：

1. **组合覆盖率**：截图 `04_组合建议_三张推荐卡.png` 显示物化地「739 / 821 专业、88 个专业类」→ 对应 `02-规则与数据表/表2_组合覆盖率汇总.csv` 第 2 行 → 对应代码 `subjects.coverage(['物理','化学','地理'])`。
2. **专业映射**：`表3_专业到专业类映射样例.csv` 的 246 行，抽任意一行用 `subject_map.group_of_major("专业名")` 可得同一结果。
3. **院校位次**：截图 `09_院校优势_抽屉.png` 里「中国科学院大学 691 分 / 位次 177 / 来源河北」，可在 `backend/data/he/toudang_2026.csv` 中检索到原始行。

## 材料的边界（主动披露）

- 院校实证数据只覆盖 8 个省份（江苏、广东、湖北、山西、辽宁、浙江、山东、河北），其余 23 省只有规则覆盖，没有院校级投档数据。
- 就业画像是团队整理的专业类判断，不含薪资数字、就业率、排名。
- 测评量表是自建，参考了三套公开量表的题型设计，没有常模分数。
- 调研材料尚未开展实地采集。

这四条都写进了 `04-项目文档/03_数据来源与口径说明.md` 的「数据局限」一节，也写进了产品页面的页脚。
