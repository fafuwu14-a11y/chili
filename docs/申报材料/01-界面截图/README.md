## 截图里的数据都是真的

- 04 号图的可报专业数（739 / 821、88 个专业类）与 `docs/申报材料/02-规则与数据表/表2_组合覆盖率汇总.csv` 完全一致，可交叉核对。
- 08 号图的 360 冲 / 37 稳 / 3282 保，来自八省投档表的真实位次换算，不是随机数。
- 09 号图的院校位次来自江苏、广东、湖北、山西、辽宁、浙江、山东、河北八省考试院公开投档表。
- 12 号图带「样例数据」角标——因为培优扶弱依赖用户自己的测评结果，截图时用的是内置样例（江苏物理向 78 / 71 / 58 / 46 / 39 / 52），页面已明确标注，不冒充真实用户数据。

## 复现方法

```bash
cd E:\大肥鱼工作区\gaokao-platform
python -X utf8 run.py --port 8011 --no-open
# 另开一个终端，用任意浏览器打开 http://127.0.0.1:8011/
```

问卷类截图需要先完成测评（23 题约 6 分钟），或直接访问 `http://127.0.0.1:8011/growth.html?demo=1` 查看培优扶弱样例。
