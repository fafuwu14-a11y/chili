# 02 · 规则与数据表

对应《申报书》第六部分（二）「规则与数据表」。所有表格由 `backend/app/` 里的规则模块直接导出，不是手工誊写，重跑脚本即可得到同一份数字。

## 表 1 十二种组合 × 92 个专业类可报性

文件：`表1_十二种组合×92专业类可报性.csv`

- 行：江苏（3+1+2）的 12 种组合，按「物理+化学+生物」等顺序排列
- 列：92 个本科专业类，单元格为「可报 / 不可报」
- 末列：该组合可报的专业类数量
- 判定依据：`backend/app/subjects.py` 的 `MAJOR_GROUPS`（每个专业类带 `required` / `any_of`）+ `group_eligible()`

## 表 2 组合覆盖率汇总

文件：`表2_组合覆盖率汇总.csv`

| 组合 | 可报专业类 | 专业类覆盖率 | 可报专业 | 专业覆盖率 |
| --- | ---: | ---: | ---: | ---: |
| 物理+化学+政治 | 91 / 92 | 98.9% | 753 / 821 | 91.7% |
| 物理+化学+生物 | 88 / 92 | 95.7% | 739 / 821 | 90.0% |
| 物理+化学+地理 | 88 / 92 | 95.7% | 739 / 821 | 90.0% |
| 物理+政治+地理 | 32 / 92 | 34.8% | 258 / 821 | 31.4% |
| 物理+生物+政治 | 33 / 92 | 35.9% | 262 / 821 | 31.9% |
| 历史+化学+政治 | 30 / 92 | 32.6% | 243 / 821 | 29.6% |
| 历史+政治+地理 | 29 / 92 | 31.5% | 237 / 821 | 28.9% |

其余 5 种组合见表内。这张表就是「物理+化学几乎覆盖全部理工医学、历史类在理工农医上几乎全线关闭」这句话的出处——不是形容词，是 821 个专业的逐个判定结果。

口径说明：

- **专业数**按 `major_catalog.json` 的 821 个本科专业计，同一专业只算一次
- **专业类**按 92 个本科专业类计，不按 12 个学科门类
- 覆盖率 = 可报专业数 ÷ 821，不含「试验班 / 预科班」等不指向具体专业的名目

## 表 4 就业画像字段与数据来源

来源：`backend/app/major_outlook.py` 的 `build()` 返回值。

| 字段 | 含义 | 数据来源 | 更新方式 |
| --- | --- | --- | --- |
| `major` / `group` / `category` | 专业、专业类、学科门类 | 《普通高等学校本科专业目录》 | 随目录版本更新 |
| `source` | 该画像取自专业类还是单个专业 | 程序判定 | 自动 |
| `verdict` | 一句话综合判断（上限与下限） | 团队整理 | 年度复核 |
| `what` | 四年学什么、课程怎么分岔 | 培养方案与课程大纲 | 年度复核 |
| `market` | 就业去向的四条主线 | 高校就业质量报告、行业公开招聘口径 | 年度复核 |
| `risk` | 代价与风险（学历门槛、周期、替代） | 公开报告 + 团队研判 | 年度复核 |
| `path` | 大一到大四的四年路线 | 团队整理 | 年度复核 |
| `signal` | 招生规模、开设省份等可核验信号 | 八省投档表（省级考试院公开数据） | 随招生季更新 |
| `basis` | 口径声明（提示「具体到学校还会差很多」） | 程序生成 | 自动 |

**边界**：`market` 与 `risk` 是文字判断，没有精确薪酬数字；平台不编造薪资区间与排名。`signal` 是唯一带数字的字段，且能回溯到具体省份与年份的投档表。
