# 赤鲤 · AI 接入指南（小白版）

> 这份文档写给**完全不懂技术**的同学和家长：照着点，10 分钟就能让平台里的
> 「AI 选科追问」「个性化解读」跑起来。
>
> 写于 2026 年 11 月。厂商界面和价格常变，**按钮名字大同小异，价格一律以官网为准**。

## 一、先搞懂三件事

### 1. 为什么要自己填 Key？

AI 不是平台自己养的。每次让 AI 说一句话，背后都是某家公司在用显卡算，按字数收费。
所以需要一把「钥匙」（API Key）——它证明「这次调用算在谁账上」。

平台**不代付**这笔钱，也不内置任何人的 Key。原因很简单：

- 内置一把公共 Key，第二天就会被刷爆，然后所有人都用不了；
- 你的选科问答里可能有省份、成绩、兴趣这些个人信息，用你自己的 Key，数据只在你和厂商之间走。

### 2. 你的 Key 存在哪？

**只存在你自己的浏览器里**（`localStorage` 里一个叫 `chili.ai.config` 的位置）。

- 后端**不写数据库、不写文件、不打日志**；
- 每次请求时，前端把 Key 临时放进请求头带给后端，后端转发给厂商，用完即弃；
- 换一台电脑、换一个浏览器，就要重新填一次——这是正常的，不是 bug。

### 3. 不填 Key 会怎样？

平台不会瘫。所有 AI 功能会自动降级成**规则引擎**：选科组合照样能算、专业照样能推荐，
只是少了「像人一样追问」和「一段一段给你讲为什么」。想体验完整版再填。

## 二、3 分钟快速开始（以 DeepSeek 为例）

1. 打开 <https://platform.deepseek.com/sign_up>，用手机号或邮箱注册，按提示完成实名。
2. 登录后看左侧菜单，点 **「API keys」**。
3. 点 **「创建 API key」**，名字随便写（比如 `chili`），确定。
4. **立刻复制**弹出的一长串字符（`sk-` 开头）。这个窗口关掉就再也看不到了，只能重建。
5. 回到平台，打开 **AI 接入向导**（`ai-setup.html`）。
6. 厂商选 **DeepSeek**，把 Key 粘进输入框，模型保持默认 `deepseek-chat`。
7. 点 **「测试连接」**。看到「连接成功 · 用时 xxx 毫秒」就成了。
8. 点 **「保存」**。之后回到选科问答，AI 追问就会动起来。

> 充不充值？DeepSeek 新号一般有少量赠送额度，够你试几十轮。
> 真要用，充 **10 元**能用非常久（一次选科追问大约消耗几分钱）。

## 四、手把手：把 Key 填进平台

不管选哪家，最后都是同一套动作：

1. 打开平台首页 → 右上角 **「AI 接入」**（或直接访问 `ai-setup.html`）。
2. 在厂商卡片里点你要用的那家（卡片上写着「免费额度」「去申请」）。
3. 点 **「去申请 Key」**，浏览器会新开一个标签页，跳到厂商控制台；
   按第三节的说明注册、复制。
4. 回到平台页面，把 Key 粘进 **「API Key」** 输入框（注意别多复制空格）。
5. **模型**一栏：不动就是默认模型；想换就在下拉框里选。
6. 点 **「测试连接」**：
   - 成功：显示绿色「连接成功 · 用时 xxx ms」，并回一句「收到」；
   - 失败：把红色报错文字对照第五节的表处理。
7. 点 **「保存」**。配置写进浏览器，下次打开自动带出（Key 会显示成 `sk-1****`）。
8. 想换一家：回到这一页重新选、重新填、重新测，旧的会被覆盖。

> 高级用户：也可以手改「高级设置」里的 base_url（比如公司内网的 OpenAI 兼容网关、
> 自己搭的 one-api）。规则是**填到 `/v1` 这一级为止**，不要带 `/chat/completions`。

## 五、常见报错对照表

先看红色提示的第一句，对号入座：

| 你会看到 | 大概率原因 | 怎么办 |
| --- | --- | --- |
| **401** ·「API Key 无效或已过期」 | Key 复制少了/多了空格；Key 被删了；拿了 A 家的 Key 填到 B 家 | 回厂商控制台**重新复制一整串**；确认厂商选对了；删掉旧 Key 重建 |
| **403** ·「这个 Key 没有调用权限」 | 没实名；没在控制台「开通模型」；Key 被设了 IP 白名单；欠费 | 先实名；到控制台把该模型**开通**；检查 Key 权限；充值 |
| **404** ·「接口地址或模型 id 不对」 | base_url 少了 `/v1`；模型名抄错（豆包/硅基流动最容易）；填成了网页地址 | 用平台默认 base_url；模型名从下拉框选，别手打；确认地址以 `/v1`、`/v3`、`/v4` 结尾 |
| **429** ·「触发限流或余额不足」 | 短时间问太快；免费额度用完；账户欠费 | 等 1~2 分钟再试；到控制台看余额/免费额度；换 `glm-4-flash` 这类免费模型 |
| **请求超时（60s）** | 网络慢；模型在「思考」；本地模型还没加载完 | 重试一次；换 `flash`/`turbo` 这类快模型；把超时调到 120 秒；本地模型先手动跑一次预热 |
| **连不上 / 502** | 断网；需要代理；本地 Ollama 没启动 | 检查网络；OpenRouter 要能上外网；本地模型先执行 `ollama serve` |
| **CORS / blocked by CORS policy** | 在浏览器里**直接**请求了厂商接口 | 别在前端直接 `fetch` 厂商地址，一律走平台的 `/api/ai/chat` 后端代理；平台已经处理好跨域 |
| **接口返回的不是 JSON** | base_url 填成了厂商官网/文档页 | 改成 API 地址（`/v1` 结尾那种），不是 `www.xxx.com` |
| **模型没有按 JSON 返回** | 小模型不会稳定输出 JSON | 换 `deepseek-chat` / `qwen-plus` / `glm-4-plus`；或重试一次 |
| **返回了空内容** | 模型名对但该模型不支持当前参数 | 换默认模型；把 max_tokens 调大一点 |

小技巧：报错文字里如果带 `sk-1****`，那是你当前填的 Key 的**脱敏形式**，
用来帮你确认「填的是哪一把」，不是泄露。

## 六、本地模型：一分钱不花，数据不出门

适合：家里电脑内存 ≥ 8GB，愿意等 5GB 下载。

### 1. 装 Ollama

- 打开 <https://ollama.com/download>，下载 Windows 安装包，双击装好。
- 装完它会在后台常驻（右下角托盘有个小羊驼图标）。

### 2. 拉一个中文模型

打开「命令提示符」（Win+R 输入 `cmd` 回车），执行：

```bat
ollama run qwen2.5:7b
```

第一次会下载约 5GB，下载完直接进入对话界面，输入「你好」能回话就说明模型跑起来了。
输入 `/bye` 退出对话（模型服务还在后台）。

> 内存 16GB 以上可以试 `ollama run qwen2.5:14b`，效果更好但更慢。
> 显卡是 N 卡的话会自动用 GPU，速度快很多。

### 3. 接到平台上

- 厂商选 **「本地模型（Ollama）」**；
- base_url 保持 `http://127.0.0.1:11434/v1`；
- 模型填 `qwen2.5:7b`（必须和 `ollama list` 里显示的名字**一模一样**）；
- API Key 随便填，比如 `local`（Ollama 不校验，但有些版本空着会报错）；
- 点「测试连接」。

> vLLM / LM Studio 也一样：它们都能开一个 OpenAI 兼容端口
> （vLLM 默认 `http://127.0.0.1:8000/v1`，LM Studio 默认 `http://127.0.0.1:1234/v1`），
> 把 base_url 换掉即可。

### 4. 本地模型的脾气

- 7B 小模型**不太会稳定输出 JSON**，AI 解读可能失败，多试一次或换云端模型；
- 第一次提问会慢（要加载模型进内存），之后就快了；
- 笔记本拔了电源会降频，速度明显变慢，属正常。

## 七、安全提醒（请务必看完）

1. **绝对不要把 Key 提交到 GitHub / Gitee**。
   截图、录屏、issue、聊天记录里也别露出来。GitHub 上有机器人专门扫 `sk-` 开头的串，
   扫到几分钟内就会被盗刷。
2. **公用电脑用完清空**：在 AI 接入页点 **「清除配置」**，或退出浏览器时清理站点数据。
   只关标签页不算清空，`localStorage` 还在。
3. **Key 泄露了怎么办**：立刻去厂商控制台**删除**这把 Key，再新建一把。
   删除是立刻生效的，旧 Key 再也调不动。
4. **一把 Key 只给自己用**。不要发给同学「试试」，账单算你的。
5. **别把 Key 发给任何自称客服的人**。厂商客服永远不会问你要 Key。
6. 平台后端**不存 Key、不写日志**，但请求确实会经过后端内存转发——
   如果你连这个也不放心，就用本地模型（第六节），数据一步都不出你的电脑。

## 八、常见问题

**Q：填了 Key 还是不能用？**
先点「测试连接」。测试通过但功能不动的，刷新页面（Ctrl+F5）再试；还不行就看浏览器 F12
的 Console 有没有红色报错。

**Q：一把 Key 能同时给几个人用？**
技术上可以，但额度共享、容易被限流，不建议。每人自己申请一把最稳。

**Q：哪家最便宜？**
纯文字对话：硅基流动的 7B 小模型 < 豆包/通义/混元 < DeepSeek < Kimi。
但要效果和价格平衡，**DeepSeek 是默认推荐**。

**Q：AI 说的话能全信吗？**
不能。选科政策、专业要求以**本省考试院当年公布的文件**为准，AI 只帮你理思路。
平台里所有专业数据都标了来源，AI 解读只是「参考意见」。

**Q：会不会偷偷扣费？**
平台不会。扣费只发生在厂商侧，按你实际调用量算；不放心可以只在厂商控制台充最小额度（10 元），
用完再充。

**Q：换电脑要重新填吗？**
要。Key 存在浏览器里，不同步。这也是安全设计的一部分。
