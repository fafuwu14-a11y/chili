# 可行性分析：专业匹配深化（方向细分 / 四条出路 / 四年预警）

> 对应 `DESIGN-home-match-v2.md`。本文只回答一个问题：**这些数据到底能不能拿到、拿得到多少、要花多少**。
> 所有探测在 2026-10-30 实测，状态码与字节数是真实返回值，不是估算。

---

## 0. 结论先行

| 能力 | 能否做出可信版本 | 靠什么 | 工作量 |
| --- | --- | --- | --- |
| 方向细分（大类 → 具体专业） | **能，且质量可控** | 教育部《本科专业目录》公开 + 人工映射 | 低 |
| 四年后预警 | **能真算** | 我们已有的 9 省招生计划 + 位次趋势 + 教育部增撤名单 | 低 |
| 考公优势 | **能做"规则版"，做不了"实时岗位版"** | 各省《公务员考试专业参考目录》公开；国考职位表需逆向 | 中 |
| 考研难度 | **能做档位版** | 学位授权点名单公开；研招网目录接口需逆向 | 中 |
| 就业去向 / 起薪 | **只能做"文献版"，覆盖约 50 个高频专业** | 麦可思公开摘要、学科评估、统计年鉴 | 中高 |
| 创业适配 | **只能定性** | 无数据，靠规则打标签 | 低 |

一句话：**方向和预警能做实，四条出路只能"说得清楚但说不精确"**。方案里对出路的每个数字都必须挂着来源和年份，不能编。

## 2. 逐项可行性

### 2.1 方向细分：**可行，质量靠人工**

| 数据 | 可得性 | 说明 |
| --- | --- | --- |
| 教育部《普通高等学校本科专业目录（2024 年版）》 | 公开 PDF | 12 门类 / 93 专业类 / 800+ 专业，含专业代码、学位授予门类、修业年限 |
| 各专业"学什么" | 公开（阳光高考专业库、各校培养方案） | 阳光高考 412，但专业简介在教育部目录与各校官网都有，人工写 180 条即可 |
| 方向题设计 | 我们自己设计 | 五级量表，和现有问卷同一套机制 |

**唯一风险是人工映射的准确性**。控制手段：每个大类 ≥6 个专业、每个专业必须挂到某大类、专业代码唯一、总数 ≥150，全部写成测试。

**成本**：15–25 万 token。

### 2.2 四年预警：**可行，且是我们最有优势的一项**

不需要新数据源，全部来自已入库的 9 个省份：

| 指标 | 数据来源 | 现状 |
| --- | --- | --- |
| 招生计划同比 | `backend/data/{zj,he,sd,cq,ln,...}/toudang_*.csv` 的 `plan` 字段 | 浙江 18,543 条全有 plan；河北、山东、重庆部分有；江苏、广东、山西、湖北、辽宁暂无（用招生单位数量代理） |
| 位次漂移 | 同一 `(code, unit_code)` 跨年匹配 | 已有 3 年数据，回测脚本现成 |
| 增撤专业信号 | 教育部每年 3 月《普通高等学校本科专业备案和审批结果》 | 公开新闻稿 + 附件表格，一年一次，成本极低 |

**注意**：只有 9 个省，样本不代表全国。展示时必须写"基于 9 省样本"，不能写成"全国该专业扩招 20%"。

**成本**：20–35 万 token（含 9 省 plan 字段补全与跨年匹配调参）。

### 2.3 考公：规则版可行，实时版脆弱

**规则版**（推荐先做）：
- 数据：各省人社厅公布的《公务员考试专业参考目录》——江苏、广东、山东、浙江都在官网挂 PDF/Excel，格式稳定；
- 做法：把"专业参考目录里的专业名 → 可报岗位类别"做成映射，输出"该专业可报 N 类岗位 / 其中不限专业 M 类"；
- 局限：**这是"能不能报"，不是"有多少岗、多少人抢"**。展示时必须写清。

**实时版**（P3 再做）：
- 需要国考职位表（`bm.scs.gov.cn` 的 SPA 接口）+ 各省省考职位表；
- 好处是能算"招录人数 / 报名人数 / 竞争比"；
- 坏处：接口每年改版、省考格式各省不同、职位表里"专业要求"字段是自由文本（"计算机类、软件工程、网络工程"），要写模糊匹配，精度存疑。

**成本**：规则版 20–30 万 token；实时版 80–150 万 token 且每年维护。

### 2.4 考研：档位版可行

| 数据 | 可得性 | 用途 |
| --- | --- | --- |
| 学位授权点名单（一级学科/专业学位） | 教育部公开，年度更新 | 统计"该专业有多少招生单位" |
| 学科评估等级（A+/A/B+…） | 学位中心公开，但站点偶发连不上 | 做"该专业在全国的层次" |
| 研招网专业目录（招生人数、推免比例） | **SPA，需逆向** | 想要精确"推免占比"只能走这条 |

**做法**：先用"硕士点数 + 学科评估等级 + 专业性质（临床医学/法学这类天然要读研）"做三档：**必须读研 / 读研加分 / 本科够用**，每档配一句解释。

**成本**：25–40 万 token（不含研招网逆向）。

### 2.5 就业：最大的短板

现实是这样的：

| 想要的数据 | 官方有没有 | 我们能拿到的 |
| --- | --- | --- |
| 分专业就业率 | 有，但散在 **2,800+ 所高校的《毕业生就业质量年度报告》PDF** 里，格式各校不同 | 头部 200 所可解析，覆盖率不到 8% |
| 分专业起薪 | 麦可思《中国大学生就业报告》**付费**（几千到几万元） | 每年 6 月新闻稿里有 20–50 个高频专业的月收入片段 |
| 行业平均工资 | 国家统计局年鉴，**接口 403** | 可人工录入年鉴表（20 个行业 × 城镇非私营单位），一年一次 |
| 岗位需求趋势 | 招聘平台，均有反爬 | — |

**结论**：做**"文献版"**——每个大类给三段：
1. 主流去向（3 个典型岗位/行业）
2. 起薪区间（引用麦可思公开摘要，标年份与"全国本科"口径）
3. 集中行业（引用统计年鉴行业分类）

**明确不做**：不给"该专业就业率 92.3%"这种伪精确数字。

**成本**：30–50 万 token（含 50 个高频专业的人工整理）。

### 2.6 创业：只能定性

没有任何官方"专业—创业"数据。只能靠规则打标签：

| 标签 | 判断依据 | 例子 |
| --- | --- | --- |
| 资质门槛高 | 需要执业资格（医学、法学、教育、建筑） | 临床医学 → 不能本科创业行医 |
| 资本门槛高 | 需要重资产（制造、航空、能源） | 机械 → 创业多在供应链端 |
| 技能可迁移 | 通用技能（设计、编程、营销、外语） | 软件工程 → 接项目门槛最低 |
| 靠人脉/资源 | 需要客户关系（金融、传媒、行政） | 金融 → 个体创业较难 |

四个标签 + 一句人话说明，**不评分、不排名**。

**成本**：8–12 万 token（21 大类 × 4 标签，人工判断）。

---

## 3. 三条退路（如果硬数据始终拿不到）

1. **档位化**：所有数字换成分档（高/中/低），配"依据 + 年份"，绝不给小数点；
2. **来源化**：每个结论后面挂 `[麦可思 2025]` `[教育部 2024 目录]` `[9 省样本 2026]` 这样的角标，点开看原文；
3. **让用户自己判断**：提供"问自己三个问题"的引导（要不要读研、能不能接受考证、想不想进体制），而不是替他下结论。

## 4. 分阶段成本汇总

| 阶段 | 内容 | token | 折合（flash 空闲价） |
| --- | --- | --- | --- |
| P0 门户 + 目录 | 主页、导航、`predict.html` 拆分、180 个专业目录、详情页骨架 | 70–110 万 | 0.8–1.5 元 |
| P1 方向 + 预警 | 方向题、细分打分、四年预警（9 省） | 60–100 万 | 0.7–1.3 元 |
| P2 四条出路 | 考公映射、考研档位、就业文献、创业标签 | 50–90 万 | 0.6–1.2 元 |
| P3 实时数据（可选） | 国考职位表、研招网目录逆向 | 100–200 万 | 1.2–2.6 元 |

**风险准备金**：官方站改版/加 WAF 的概率不低（这次实测已经遇上 3 个），P3 建议按 1.5 倍估。

## 5. 合规与表述红线

| 红线 | 具体做法 |
| --- | --- |
| 不能声称"就业率"是自己统计的 | 引用一律写明"麦可思 2025""教育部 2024"，自己不做二次加工 |
| 不能给"包就业/保录取"承诺 | 全站统一免责行，方案页已有 |
| 不能把 9 省样本说成全国 | 预警文案固定带"基于 9 省样本" |
| 第三方数据不能整段搬运 | 只摘录数字与结论，不复制原文段落 |
| 用户专业选择属个人决策 | 结果页永远保留"最终由你自己决定"这类句子 |
