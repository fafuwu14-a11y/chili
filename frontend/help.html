四步上手

  1. 先做专业匹配。 选一套问卷（18 / 34 / 48 题），按「完全不认同 → 非常认同」点五档， 大概 3–10 分钟。结束会给出 21 个专业的匹配度，以及每个专业适合先看的课。
  2. 再测录取概率。 填省份、科类、分数（位次可留空，会自动换算），拿到按「匹配度优先」排好的专业组列表。 点任意一张卡片，能看到该院校近两年的真实投档线和同分排序项。
  3. 生成冲稳保方案。 一键把结果排成 4 冲 / 8 稳 / 6 保（数量可改），按顺序编号，支持复制文本和打印成 PDF。
  4. 开学前先听一门课。 拿目标专业去「专业先导课」，挑 4–6 周的入门课试听，判断自己是不是真喜欢。

账号与登录

  • 怎么注册？打开任意页面会跳到登录页，切到「注册」，用邮箱 + 密码（至少 8 位，含字母和数字）即可，注册后自动登录。
  • 要邮箱验证码吗？不需要。邮箱只作为账号名使用，本站不会给你发营销邮件。
  • 为什么每次都要登录？登录状态默认保持 7 天，期间正常使用会自动续期。超过 7 天没用需要重新登录。
  • 能在几台设备用？同一账号可以在多台设备登录，互不影响。在任意一台退出只影响那一台。
  • 想换个密码？目前没有自助改密入口。发一封邮件到下方「联系我们」的地址，标题写「修改密码」，正文带注册邮箱和你想用的新密码，我们改好后回信确认。

忘记密码怎么办

本站不发邮件、也没有短信通道，所以没有「点链接自助重置」。重置由人工完成，一共三步：

  1. 用任意能收到回信的邮箱，发到下方「联系我们」的地址，标题写「重置密码」。
  2. 正文写清注册邮箱，再补一条只有你知道的信息（省份 + 科类 + 你大概的分数档位），用来确认账号归属。
  3. 1–3 个工作日内，我们会把该账号重置成一个临时密码回给你；用它登录后，再发一封信说明你想换的新密码即可。

临时密码只用于登录，建议尽快换成自己的。我们不会向你索要原密码， 也不会在邮件里让你点任何链接——凡是让你点链接填密码的，都不是我们。

自己部署 / 本地运行的版本

源码运行的话，不用等人：在 gaokao-platform/backend 目录下执行下面这行， 把邮箱和 NewPass123 换成你自己的，密码会立刻生效。 

python -c "import sqlite3; from app.auth import make_password_hash; con = sqlite3.connect('data/app.db'); con.execute('update users set password_hash = ? where email = ?', (make_password_hash('NewPass123'), '你的注册邮箱')); con.commit(); print('done')"

exe 版把上面的 data/app.db 换成 exe 同级目录下的 data/app.db。 如果连邮箱也记不清了，可以直接删掉 users 表里那一行再重新注册， 代价是这个账号存的方案记录会一起被删掉。

数据与准确度

  • 数据来自哪里？公开的省级招生考试机构文件：普通类本科批投档线、逐分段统计表。详见数据来源。
  • 覆盖多少？八个地区：江苏、广东（2024–2026 三年）、山西（2025–2026）、湖北（仅 2026），物理类与历史类都有；辽宁、浙江、山东、河北是「专业+学校」模式，投档单位直接就是具体专业（浙江、山东为综合改革，只有一个科类），浙江另有 2026 年的招生计划数。只收录投档分数齐全的省份，缺数据的省份不占位。
  • 准不准？江苏 2025→2026 回测：分数误差中位数 8 分，六成在 10 分以内；分档命中率保 95%、稳 76%、冲 21%。其余省份数据年份不够，暂未独立回测。详见回测与误差。
  • 为什么没有招生计划人数？投档线文件本身不含计划数，我们在页面上用「—」表示未知，不编造数字。

常见问题

分数和位次都填会怎样？

以位次为准。位次是录取里更稳的坐标，分数每年难度不同、不能直接比较。

为什么有的专业组显示「—」而不是计划人数？

官方投档线文件没有这一列。我们只展示有来源的数据。

概率 50% 是不是就有一半机会？

这是我们模型给出的估算值，含义是「按去年的录取位次与本年的误差分布，你这个位次大致处在边界附近」。它不是真实概率，也不能保证结果。

为什么同分的专业组预测位次一样？

因为投档线只精确到分，同一分数对应的位次由逐分段表换算而来，所以同分必然同位次。

能在手机上看吗？

可以，页面适配了手机宽度。冲稳保方案建议用电脑打印，A4 竖版一页排得下。

数据什么时候更新？

每年投档线公布后（一般在 7 月中下旬）更新一次，页面顶部会显示「数据更新至」的时间。

会不会以后收费？

目前完全免费，也没有广告。如果将来有变化，会提前在本页和登录页说明。

我的分数会被存下来吗？

不会。分数和位次只在请求过程中参与计算，不写入数据库。详见隐私政策。
